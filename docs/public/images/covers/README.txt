本地封面均为本项目编写的原创 SVG，无远程素材和字体依赖。
grove.svg：槐树与山色；writing.svg：纸张与写作；cloud.svg：云与静态发布。

文章明确指定的普通 cover 原样优先；未填写时按文章扫描顺序选择本地封面，本次浏览中固定。
三篇现有文章明确指定的是同一随机接口，不修改其 Frontmatter：Cover 通过官方 JSON 多图接口取得独立地址。
同次浏览只取一次 JSON，按文章索引保存选择；重复链接、超时、不可读大小或超过 256 KiB 的原图使用各自本地封面。
远程图片仍可能内容相同，不承诺图库绝对无重复；本地三张图本身不同，文章超过三篇时本地池允许复用。
不下载或镜像第三方图片，不附加时间戳；固定图片地址由浏览器缓存，站内切换复用同次选择。
这是文章封面池，不读取或修改 docs/public/img/ 随机背景池，也不作为 SEO 分享图输入。
