槐序霁随机背景图片池

请自行放入具有使用权限的风景图片，本目录不附带或下载原神素材。
支持 JPG/JPEG、PNG、WebP、AVIF（扩展名大小写均可），只扫描当前目录顶层。
单张限制：不超过 3,000,000 字节（3 MB）；超过限制会在构建时简短提示并排除。
2 Mbps 带宽下建议优先使用 300–800 KB、主体居中的横向图片；移动端会居中裁切。
系统不会修改、转换或自动压缩原图，README 等非图片文件不会进入清单。

使用步骤：
1. 把图片复制到 docs/public/img/，例如 landscape.webp。
2. 开发时重启 npm run docs:dev；发布时执行 npm run docs:build，自动重新扫描。
3. 完整打开或刷新页面后，随机选中一张；站内路由切换和打开面板都不会换图。
4. 将 docs/.vitepress/dist/ 整体交给已有静态部署流程，图片访问地址为 /img/文件名。

每次刷新独立随机，允许连续两次恰好选中同一张；不使用定时轮播，不预载整个图片池。
空目录或选中图片加载失败时，使用现有 CSS 背景底色和柔光兜底，不会逐张重试。
单张背景在 CSS 固定视口中 cover 居中展示，保留现有卡片、字体、标题和导航。
超过大小限制的图片会被排除在前端清单外；原文件仍由 public 目录原样复制，不会被删除。

缓存说明：本功能不改变托管服务器响应头。同名替换图片后若线上缓存未更新，请更换文件名再构建。
背景加载不阻塞正文和备用字体显示；真实背景耗时取决于图片体积、网络和浏览器缓存。
